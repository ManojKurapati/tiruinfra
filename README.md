# Tiruinfra

Premium single-scroll marketing site for Tiruinfra — a turnkey civil and structural construction company.

Built with Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS v4, Motion (Framer Motion v12), Lenis smooth scroll, and a sharp-based image pipeline.

## Local development

```bash
npm install
npm run dev          # http://localhost:3000
```

Other scripts:

```bash
npm run build        # production build (static export to ./out)
npm run lint
```

## Deploying

This project is configured for static export and deploys to two targets from a single `npm run build`:

### Vercel
Import the repo at [vercel.com/new](https://vercel.com/new). No env vars required. Every push to `main` triggers an auto-deploy.

### GitHub Pages
A workflow at `.github/workflows/deploy.yml` builds the site with `GITHUB_PAGES=true` (which sets `basePath: /tiruinfra`) and publishes the `out/` directory to GitHub Pages on every push to `main`.

To enable it, in the repo settings: **Settings → Pages → Source: GitHub Actions**.

## Image pipeline

Source photos live outside the repo; the project ships pre-optimized WebP variants in [public/images/](public/images/) generated by [scripts/optimize-images.mjs](scripts/optimize-images.mjs).

## Structure

```
├── layout.tsx       # Fonts, metadata, JSON-LD, preloader, cursor, smooth scroll
├── page.tsx         # Composes the 11 sections
├── globals.css      # Tailwind theme, noise overlay, cursor styles
├── robots.ts        # SEO
└── sitemap.ts       # SEO
```
